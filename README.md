## 🔧 How to Use

1. **After installation**, open the youtube-music app from your Start Menu or desktop shortcut.
2. **Sign in** with your YouTube Music account (or use it without signing in—it still works for search and playback).
3. **Search** for music by typing into the search bar. Press Enter to see results.
4. **Click** on any song to start playing it. Use the volume, play/pause, and next/previous buttons.
5. **Create playlists** by clicking the "Playlist" button and adding songs. You can see and manage them later.
6. **Close or minimize** the window and your music will keep playing in the background.

## ❓ Frequently Asked Questions

**Does it work without a subscription?**
Yes. youtube-music uses YouTube Music's free tier, so no premium subscription is needed. You can still search, listen, and create playlists.

**Will it work on Mac or Linux?**
The app is currently built for Windows. If you need a version for other operating systems, check the repository's releases page for confirmation.

**Is it safe?**
Yes. youtube-music is open source, which means anyone can review the code. It does not include any harmful or hidden software. Download only from the official GitHub releases page.

**Why does the app need internet?**
The app streams music directly from YouTube Music, so an active internet connection is required. Background playback will stop if the connection is lost.

**Can I download music for offline listening?**
No, this version does not support offline playback. It streams in real time, like Spotify free or YouTube Music.
